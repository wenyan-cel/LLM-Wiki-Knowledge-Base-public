# 国内图像视频 API

## 一句话定义

国内图像视频 API 是面向文生图、图生图、图生视频和剪辑合成的服务接口，例如万相、火山、可灵、MiniMax 和自建 compose 服务。

## 为什么重要

Dify、Coze 等编排平台本身不是图像/视频模型。生产级落地需要稳定的 API 接入、鉴权、轮询、限流、失败降级和临时 URL 转存。

## 核心要点

- 文生图适合氛围图和背景图。
- 图生图适合使用参考图控制产品外观，是电商贴产品的关键。
- 图生视频适合短动效，但需控制运动幅度。
- 自建 media-gateway 可以统一供应商、鉴权、轮询、转存和响应格式。
- API 结果 URL 常有时效，需要转存到自有 OSS/CDN。

## 相关服务

- 阿里通义万相：文生图、图生图、异步任务。
- 火山 Seedream/视觉智能：图像生成。
- 可灵 Kling：图生视频。
- MiniMax 海螺：图生视频。
- 自建 FFmpeg/compose 服务：分镜图合成 MP4。
