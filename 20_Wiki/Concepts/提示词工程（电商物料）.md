# 提示词工程（电商物料）

## 一句话定义

电商物料提示词工程，是把产品主体、场景、构图、光线、风格、品牌约束、画幅和合规限制结构化为可复用模板。

## 为什么重要

电商素材要求既快又稳定。提示词不能只追求好看，还要服务 SKU 一致性、渠道差异、文字安全区、A/B 测试和合规审核。

## 核心要点

- 推荐结构：主体 + 场景 + 构图 + 光线 + 风格 + 品牌约束 + 画幅/质量。
- 多数图像模型对英文 prompt 更稳，但口播和业务文案应保留中文。
- `visual_dna` 应作为统一风格后缀，保证批量素材风格一致。
- `negative_prompt` 用于抑制畸形、乱码、Logo、水印、低质、误导性文字。
- 分镜 JSON 应包含 `duration_sec`、`narration_cn`、`image_prompt_en`、`negative_prompt`、`subtitle_safe_area`、`motion` 等字段。
- 版本管理字段包括 `prompt_version`、`seed`、`model_id`、`run_id`。

## 应用案例

- 美妆：柔和光线、洁净浴室/梳妆台、质地 macro、避免绝对化功效。
- 3C：暗色科技渐变、轮廓光、功能抽象可视化、避免伪造参数和竞品 Logo。
- 服饰：自然街拍、面料细节、版型一致、避免模仿名人和夸张显瘦宣称。
