# 电商 AI 物料工作流

## 一句话定义

电商 AI 物料工作流，是把 SKU Brief、品牌知识、分镜、提示词、图像/视频 API、审核和回写串起来的可复盘生产线。

## 为什么重要

单次对话出图很难批量、追踪和复盘。电商场景更需要固定输入输出、版本号、任务日志、表格批量和人工终审。

## 核心要点

- Dify 更偏 `Workflow 编排 + 知识库检索 + HTTP 工具`。
- Coze 更偏 `Bot 触达 + 工作流 + 插件 + 飞书生态`。
- 两者共同点是：LLM 负责结构化分镜和提示词，外部图像/视频服务负责生成，合规和回写必须进入流程。
- 推荐双轨：探索轨用于单 SKU 试风格和改稿，生产轨用于表格批量和 API 夜跑。
- 表格字段应保留 `prompt_version`、`run_id`、`asset_url`、`channel`、`reference_url`，便于复盘。

## 实践方法

1. 用表格收集 SKU、卖点、渠道、参考图和合规禁忌。
2. 用 LLM 输出结构化分镜 JSON。
3. 逐镜调用图像 API，必要时使用 reference image。
4. 对低风险镜头使用图生视频，对主流程使用分镜合成。
5. 用合规 LLM 和人工终审兜底。
6. 回写素材链接、版本号和运行 ID。
