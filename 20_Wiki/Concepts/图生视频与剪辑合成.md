# 图生视频与剪辑合成

## 一句话定义

图生视频是用关键帧生成短动效，剪辑合成是把分镜图、字幕、BGM 和运动参数合成为更可控的视频。

## 为什么重要

电商视频既要有动感，也要保持产品真实稳定。通用图生视频容易让产品边缘、包装文字和结构漂移，因此很多场景下剪辑合成比直接图生视频更稳。

## 核心要点

- 图生视频适合氛围、空镜、轻运动和 hero 镜试验。
- 产品细节、包装文字、Logo、参数不应交给图生视频模型承载。
- 分镜图 + Ken Burns + 字幕 + BGM 是更可审计的主流程。
- `motion` 字段可以映射到 compose 服务或视频 prompt。
- 图生视频 API 多为异步任务，需要轮询、失败重试和结果转存。

## 应用案例

- 美妆 hero 镜可尝试 5 秒慢推近。
- 3C 产品功能镜适合 compose，避免耳机结构变形。
- 服饰街景镜可以轻 motion，但需要人工核对版型和颜色。
