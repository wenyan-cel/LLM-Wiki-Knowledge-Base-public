## 元数据

- 场景：电商产品宣传物料
- Raw：[[10_Raw/文生图视频制作-Dify-电商产品宣传物料|文生图视频制作-Dify-电商产品宣传物料]]

## 可吸收观点

- Dify 在链路中更像编排与规范中枢，负责结构化 Brief、知识库检索、提示词生成、HTTP 工具编排和审核报告。
- 电商文生图视频的关键不是全自动，而是让 80% 可模板化物料自动化，同时保留人审和实拍补位。
- 推荐用 Workflow 将 `需求 -> 分镜 -> 文生图 -> 图生视频/剪辑合成 -> 合规 -> 回写` 串成可复盘流水线。
- Prompt 版本、seed、model_id、run_id 是投放复盘和 A/B 测试的关键字段。
- 强实物、包装文字、Logo、参数等内容不能完全依赖生成模型，需要 reference image、后期叠字和人工终审。
