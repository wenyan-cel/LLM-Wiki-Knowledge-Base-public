# Coze

## 简介

Coze 在这组资料中被定位为 Bot、工作流和插件结合的业务触达型平台，可用于电商运营在对话、飞书表格或 API 中触发 AI 物料生产。

## 与本库相关

- 适合探索轨和生产轨结合。
- Bot 负责自然语言改稿、试风格和触发工作流。
- 工作流和插件负责批量、标准输入输出、图像/视频生成和回写。
