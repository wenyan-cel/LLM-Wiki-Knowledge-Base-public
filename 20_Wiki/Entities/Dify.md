# Dify

## 简介

Dify 在这组资料中被定位为电商 AI 物料生产的编排与规范中枢，负责把 Brief、知识库、LLM、HTTP 工具、合规审核和回写串成 Workflow。

## 与本库相关

- 适合标准化、可追踪、可复盘的生产轨。
- 可通过知识库检索品牌、合规、类目话术。
- 可通过 HTTP 工具接入图像/视频 API 或 media-gateway。
