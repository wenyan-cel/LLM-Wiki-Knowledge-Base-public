# AI 文生图电商物料实践路线图

## 结论

电商 AI 文生图视频落地不应追求一步到位的全自动，而应从“分镜与提示词标准化”开始，逐步进入“场景图自动化”和“短视频合成自动化”。Dify 与 Coze 都可以承载这条路线，差异主要在触达方式和编排生态。

## 4. 应用案例

### 美妆

- 适合柔和氛围、质地 macro、成分可视化。
- 风险是功效表述和前后对比夸张。

### 3C

- 适合 hero 产品图、功能抽象可视化、暗色科技风。
- 风险是参数错误、结构变形和伪造 UI。

### 服饰

- 适合平铺、面料细节、街景穿搭。
- 风险是版型颜色漂移和模特/肖像问题。

## 5. 推荐落地顺序

1. 建立类目 Brief 模板和禁用词库。
2. 用 LLM 输出标准分镜 JSON。
3. 先做人审分镜和提示词包。
4. 接入图像 API 批量生成场景图。
5. 对强实物镜头引入 reference image。
6. 用 compose 服务生成可控短视频。
7. 将素材 URL、prompt_version、run_id 回写表格。
8. 用投放数据反向优化 Prompt 与分镜模板。
